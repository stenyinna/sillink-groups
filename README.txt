SILLINK GROUP WEBSITE

Files:
- index.html: website markup
- styles.css: responsive layout and red/white/charcoal styling
- script.js: interactive 10-sector slider, mobile navigation, and contact email form
- /sillink-logo.png: supplied logo

UPLOAD:
1. Extract this ZIP on your computer.
2. Upload the contents of the sillink-group-website folder to your website's public web root (often public_html, www, or the site's root).
3. Make sure index.html is in that root and the assets folder stays beside it.
4. Visit your domain.

This is a self-contained static website; no build step is required. The Google Fonts import uses an internet connection, with fallback fonts included. The contact form uses the visitor's default email application (mailto) rather than a server-side form service. Replace the email/phone details in index.html if your live contact details differ.

Note: This is a faithful recreation based on the public page content and supplied logo, not the original Base44 source code. Exact pixel-for-pixel duplication of proprietary source or backend behavior cannot be guaranteed.
